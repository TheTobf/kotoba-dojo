# Repo-Überblick

Zwei unabhängige Handy-Apps (PWAs), beide auf GitHub Pages:

- **Kotoba Dojo** (Japanisch lernen) – Projektwurzel, siehe `README.md`.
- **Lernzettel** (Lernzettel fürs Studium: Mathe, Externes Rechnungswesen, Internationales Management,
  Wirtschaftsinformatik) – Ordner `lernzettel/` mit eigenem `package.json`.
  **Schickt der Nutzer Studien-Unterlagen oder geht es um Lernzettel: zuerst `lernzettel/CLAUDE.md` und
  `lernzettel/FORMAT.md` lesen.** Jeder Lernzettel bekommt einen Multiple-Choice-Test.
